# Biblioteca de consola

Aplicación de terminal en Java 25 para registrar y mostrar libros.

## Características
- Record `Libro` (titulo, autor, anio)
- Almacenamiento en un array tradicional (máximo 5 libros)
- Menú de opciones, validación de datos y salida del programa

## Requisitos
- JDK 25
- IntelliJ IDEA

## Ejecución
1. Clonar el repositorio.
2. Abrir la carpeta en IntelliJ IDEA.
3. Ejecutar `Main.java` (botón verde junto a `void main()`).
